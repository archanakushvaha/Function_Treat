# 🧩 Function Treat

A beginner-friendly Python project to understand and practice **Functions**. This project demonstrates how to create, call, and use functions with different types of arguments and return values.

---

## 📖 About the Project

**Function Treat** is designed to help beginners learn one of the most important concepts in Python—**Functions**. It includes simple examples and exercises that explain how functions make code reusable, organized, and easier to maintain.

---

## 🚀 Features

- Create user-defined functions
- Call functions with and without parameters
- Use return statements
- Practice default arguments
- Learn keyword arguments
- Understand variable scope
- Simple and easy-to-read Python code
- Beginner-friendly examples

## 💻 Sample Example

```python

print(greet(user))
```
